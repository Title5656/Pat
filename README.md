# Pat (แพท)

บอท Discord สำหรับบันทึกสมาชิกเข้า–ออกห้องเสียงในเซิร์ฟเวอร์เดียว และส่งข้อความไปยังห้อง Log ที่กำหนด

URL บน Render: https://pat-discord-bot.onrender.com/

## การทำงานหลัก

- แจ้งเข้าห้อง 🟢 และออกจากห้อง 🔴 พร้อมแท็กห้องและสมาชิก
- ละเว้นการย้ายห้อง การเปลี่ยนสถานะไมค์ หูฟัง กล้อง และสตรีม
- ละเว้นบัญชีบอท
- แสดงข้อความแบบ blockquote แยกสถานะและสมาชิกให้อ่านง่าย
- บันทึกข้อผิดพลาดในคอนโซลเมื่อค้นหาห้องหรือส่งข้อความไม่สำเร็จ

## เทคโนโลยีและโครงสร้าง

ใช้ Node.js 24 และ discord.js v14 โดยโค้ดหลักอยู่ในไฟล์เดียว ไม่มีฐานข้อมูล

```text
Pat/
├── index.js                # เชื่อมต่อ Discord และจัดการเหตุการณ์ห้องเสียง
├── test/voice-log.test.js   # ทดสอบการแจ้งเตือนและกรองเหตุการณ์
├── .github/workflows/      # งานอัตโนมัติ รวมถึง CI ตรวจโค้ดและเทสต์
├── .env.example            # ตัวอย่างตัวแปรตั้งค่า
├── .gitignore              # ไฟล์ที่ไม่เก็บใน Git
├── .node-version           # เวอร์ชัน Node.js
├── package.json            # ข้อมูลแพ็กเกจและคำสั่งของโปรเจกต์
├── package-lock.json       # เวอร์ชัน dependency ที่ล็อกไว้
├── CHANGELOG.md            # บันทึกการเปลี่ยนแปลง
└── README.md               # ภาพรวมโปรเจกต์
```
